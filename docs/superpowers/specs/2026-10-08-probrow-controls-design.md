# ProBrow signal controls in OrbiT

Date: 2026-10-08

## Goal
Inspect strand-specific PRO-seq on circular genomes (chrM) in OrbiT with ProBrow's controls: smoothing, sharpening, shared Y scale, autoscale lock, sample overlay, keyboard shortcuts. Browser-only; no server, no Python, no changes to ProBrow.

## Decisions (approved in chat 2026-10-08)
- Scope: all of smooth+sharpen, shared Y, overlay, keyboard shortcuts.
- Integration: port ProBrow `transform_signal` to JS inside OrbiT.
- Zoomed-window edges are zero-padded (no margin fetch). Full-genome view wraps the kernel round the origin.

## 1. Signal pipeline: `src/signal.js` (pure)
- `gaussianSmooth(x, window, circular)`: odd window, sigma = window/6, normalised kernel, `same` output length; wraps when `circular`, else zero-pads.
- `slidingMax`, `peakPreserve(x, s, window)`: gain = max(x)/(max(s)+1e-8), clipped to [0, 5].
- `transformSignal(values, {smooth, sharpen, circular})`: smooth = window in bins (<=1 off); sharpen = unsharp strength, baseline window 9 when smooth <= 1; sharpened output clamped >= 0; otherwise peak-preserving smoothing.
- Minus strand: `abs` before transform (as ProBrow).
- Test: fixture of expected outputs generated by running ProBrow `backend/app/signal.py`.

## 2. Hook-in
- `fetchSignal` (src/app.js) applies the transform per strand after `getBinnedValues`; smooth bp -> bins via `bp / binSize`; `circular = span >= genome.length`.
- Track fields `smooth` (bp, 0 = off) and `sharpen` (0-100); panel sliders; added to session `KEYS`. Missing fields in old sessions default to off.

## 3. Y scale
- Shared Y (`p`): one symmetric max over all visible stranded tracks, post-transform, passed to `computeScale` as fixed range. Default stays per-track auto.
- Global Y factor `[` / `]` (log 0.1-10x). Autoscale lock: max frozen while rotating/zooming; `a` re-fits to current view.

## 4. Overlay
- Optional track `group` id. `computeTrackBands` collapses a group into one band; members draw in own colours with a common scale.
- Panel: per-track "overlay with" selector; ungroup restores own ring. Groups of 3+ ask for confirmation. Group saved in session.

## 5. Keyboard
- `[ ]` `a` `s/S` `k/K` `b/B` `p`, `?` help panel; existing `R` and export stay. `s/S`, `k/K` act on all signal tracks; sliders are per track.

## Out of scope
Server, Python dependency, ProBrow changes, gene-lane code.
